Menelay Live Analytics

Инструмент для анализа канала Menelay Live по запросу его владельца.

Владелец подтверждает доступ в Google. Скрипт читает статистику и сведения о роликах через API YouTube, чтобы сравнивать просмотры, подписки, источники трафика и удержание аудитории.
